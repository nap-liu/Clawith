- [x] 明确团队顶层只保留“数字员工”和“能力”。
- [x] 明确能力清单和可用范围是能力页内部视图。
- [x] 明确团队写操作采用项目负责人唯一权限口径。
- [x] 明确保留轻量协作网络，但不恢复单成员运行/快照谱系。
- [x] 明确升级为标准数字员工必须是主界面唯一直接入口。
- [x] 明确不新增权限引擎或平行团队 DTO；成员能力包、Skill 项目资产、运行冻结和模板生命周期只扩展现有归一合同。

## 十三、成员能力包与模板 Skill 生命周期

### 产品结构与成员入口

- [x] 明确每个项目数字员工独立拥有配置、工具、MCP 和 Skill 入口，不用全员共享开关覆盖成员差异。
- [x] 在同一数字员工详情内提供配置、工具、MCP 和 Skill 四个直接入口，不新增团队顶层导航。
- [x] 成员详情展示该成员当前能力包；能力页继续展示全项目能力与成员覆盖，不重复两套编辑器。
- [x] 项目负责人可编辑成员能力包，编辑者和查看者只读且不发送写请求。
- [x] 切换协作网络节点时同步切换对应成员能力包，不保留上一成员的选择、草稿或状态。

### 工具与 MCP 平台依赖

- [x] 工具和 MCP 只保存平台依赖引用及成员有效状态，不复制平台资源、凭证或个人授权。
- [x] 依赖引用使用稳定标识并保持租户边界；同名资源不得跨租户或跨来源误匹配。
- [x] 成员能力包读取统一返回工具和 MCP 的可用、缺失、受限状态及真实角色边界。
- [x] 成员停用依赖只影响该成员后续运行，不隐式改写其他成员。
- [x] 复用现有能力与项目工具 API；如需扩展，在同一成员能力包合同中归一返回，不新增平行能力接口。

### Skill 项目资产

- [x] Skill 加入项目数字员工时复制为项目 Skill 资产，并记录来源、项目归属、当前版本和成员关联。
- [x] 项目 Skill 复制完成后独立编辑、启停、升级和删除；项目变更不回写来源，来源后续变化也不自动覆盖项目资产。
- [x] 同一项目 Skill 被多名成员使用时复用一个项目资产和明确成员关联，不为每个成员重复复制相同文件。
- [x] 删除或替换项目 Skill 前返回受影响成员，并阻止产生悬空成员关联。
- [x] 所有 Skill 文件读取、复制和修改保持当前租户与项目隔离，不携带来源凭证或私密连接。

### 运行冻结

- [x] 建立统一成员能力包版本，覆盖成员配置、工具引用、MCP 引用和项目 Skill 版本。
- [x] 创建项目运行时冻结成员配置与能力包版本；运行开始后的编辑只影响新运行。
- [x] 运行、事件和审计查询能够返回当次冻结能力的稳定产品摘要，不依赖当前成员配置回算历史。
- [x] 已开始或完成的运行不得因项目 Skill 编辑、依赖状态变化或成员退出而改写冻结结果。
- [x] 后续自动协作继承发起运行的冻结成员配置、能力版本和运行身份，不读取可能已经变化的当前配置。

### 成员退出与恢复

- [x] 成员退出后禁止接收新任务和新运行，但保留历史运行、配置版本、能力包关联与项目 Skill 资产。
- [x] 退出不得级联删除仍被其他成员、历史运行或待发布模板引用的项目资产。
- [x] 已退出成员在模板发布影响清单中继续可见，不能因退出而静默忽略其 Skill。
- [x] 恢复成员时使用项目仍保留的能力包；若平台依赖已缺失或受限，先显示真实缺口，不自动替换。

### 模板发布

- [x] 发布预览逐项列出工具、MCP 和项目 Skill，以及每项受影响数字员工。
- [x] 工具和 MCP 仅写入中立依赖声明，包含稳定依赖标识、用途和真实角色边界；不包含平台资源副本、凭证或个人授权。
- [x] 每个项目 Skill 提供独立“随模板携带文件”选择，默认值为不携带。
- [x] 未选 Skill 不进入模板文件或模板能力清单，并明确列出所有受影响成员。
- [x] 已退出成员关联 Skill 使用同一逐项选择规则，不默认携带，也不从影响清单消失。
- [x] 发布确认以一张归一化清单展示 Skill 携带状态、平台依赖、真实可用性及受影响成员与计数，不重复渲染 Skill 选择控件。
- [x] 模板发布结果保存本次 Skill 携带选择和成员影响映射；此后新增 Skill 在下一次发布时仍默认不携带。

### 从模板创建

- [x] 将模板中已选择携带的 Skill 文件复制为新项目 Skill 资产，分配新项目归属和独立版本，不继续编辑模板或来源资产。
- [x] 未携带 Skill 不创建空壳记录、占位文件或虚假成员能力关联。
- [x] 对工具和 MCP 依赖逐项执行当前租户可用性核对，返回可用、缺失或受限及受影响成员。
- [x] 可用性核对不得自动安装、自动授权、复制凭证或借用模板发布者资源。
- [x] 新项目成员能力包关联到已复制 Skill 和核对后的平台依赖；缺失或受限依赖保持不可用并提供补齐路径。
- [x] 模板创建失败保持原子性，不留下半创建 Skill 文件、悬空成员关联或部分依赖状态。

### 数据模型、迁移与 API

- [x] 扩展现有成员配置合同，归一表达成员能力包、当前版本、工具/MCP 引用和项目 Skill 关联。
- [x] 建立项目 Skill 资产、版本与成员关联的数据不变量；同一资产只能属于一个租户和一个项目。
- [x] 扩展运行冻结合同，记录成员配置版本和能力包版本，并与现有运行身份冻结保持同一创建事务。
- [x] 扩展模板清单，区分平台依赖声明、选择携带的 Skill 文件和受影响成员映射。
- [ ] 提供向前迁移、可审计回填和回滚路径；既有项目能力不能被无依据转成项目 Skill 副本。
- [x] 扩展现有成员能力、模板发布和模板创建 API，避免为同一生命周期建立平行端点。
- [x] 所有写接口执行 owner 权限、租户隔离、引用存在性、版本一致性和原子保存校验。
