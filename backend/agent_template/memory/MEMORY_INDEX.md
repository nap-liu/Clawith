# Memory Structure

This file is generated by the platform to explain your persistent memory layout.
It is an ordinary workspace file.

## Core Memory

Path: `memory/memory.md`

Core Memory contains stable, important, and reusable information that should
remain available across conversations, sessions, channels, triggers, and
agent-to-agent interactions. The platform automatically loads it into every
execution turn and keeps it available throughout the complete tool loop.

## Daily Memory

Path pattern: `memory/<YYYY-MM-DD>/memory.md`

Each date directory contains the detailed work record for that date. The
platform automatically loads at most the two most recent existing Daily Memory
files into every execution turn and keeps them available throughout the
complete tool loop.

Older Daily Memory files remain under `memory/` but are not automatically
loaded. When older information is needed:

1. Call `list_files(path="memory")` to inspect available date directories.
2. Select the relevant date.
3. Call `read_file(path="memory/<YYYY-MM-DD>/memory.md")` to load its details.

Use your configured timezone to choose the current date. Keep one Daily Memory
file per date and update that file when more meaningful work occurs that day.
